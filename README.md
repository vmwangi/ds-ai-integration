# Data Science AI Integration: From Brief to Production Sprint

Interactive workshop companion. React + Vite + Tailwind, deployable to GitHub Pages.
All workshop resources (datasets, notebooks, prompts, scripts) live in public/files
and are served by the site itself.

## Run locally
npm install
npm run dev

## Deploy to GitHub Pages
1. Push this folder to a GitHub repository (main branch).
2. In the repo: Settings, then Pages, then set Source to "GitHub Actions".
3. The included workflow builds and deploys on every push to main.
Site URL: https://<your-username>.github.io/<repo-name>/
